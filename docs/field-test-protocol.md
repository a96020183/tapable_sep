# 田野實測方法（照實記錄）

本文件說明我們在校園文件列印機做了哪些實測、怎麼做、以及限制在哪。所有原始照片與影片含個資，不隨 repo 提供；整理後的機台流程見 [kiosk-flow.md](kiosk-flow.md)。

## R0：機台流程蒐集
- 明眼組員實地操作一次完整流程，拍攝 24 張畫面照片與一支操作影片。
- 整理成 12 個畫面的狀態機（語言 → 身分 → 輸入 → 選件 → 名次 → 學年期 → 確認 → 付款 → 投幣 → 列印 → 取件），含 600 秒逾時與只寫在機台貼紙上的在地知識（勿投 1 元、先按現金、悠遊卡記得取卡）。
- 這份狀態機就是 demo 模擬機台與語音流程的藍本。

## R1／R2：戴眼罩實測
- 受測者為**明眼組員蒙眼模擬**（非視障者）；視障者的真實需求另以三位視障者訪談驗證。
- 受測者自持手機，先靠觸覺找到貼紙位置，再依手機語音逐步操作實體機台；旁人只記錄、不提示。
- 記錄項目：卡在第幾步、哪一句聽不懂、有沒有找到感應區與出件口。
- 早期版本曾設計 A 版（絕對公分）／B 版（相對觸覺）兩種距離腳本；因實體量測值最終未完成蒐集，**公分引導已自 demo 移除**，目前以流程與方位引導為主，不呈現任何未經量測的距離。

## 全程情境實測
- 從一樓搭電梯到五樓、自行印出在學證明：先做無任何輔助的對照（出電梯即失去方向、機台前盲摸無法完成），再開啟 TapAble 完成流程。詳見 README「實測情境」。

## 限制（誠實揭露）
- 樣本數小、受測者非視障者，屬探索性驗證，不宜推論母體。
- 未建立量化對照組數據（例如完成秒數），本 repo 不呈現任何未實測的數字。
- 抵達判定在 demo 以視覺標記確認；真實機台的最終確認以 NFC 貼紙為準。
