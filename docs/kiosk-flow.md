# 校園「文件列印暨自動化繳費機」流程規格

紅色機身、直立式。螢幕約與視線同高，下方依序：學生證感應入口、紙鈔檢入口＋投幣口（右上）、
收據出口（中）、文件取出口（最下方）。右側貼滿手寫/列印注意事項紙條。
**逾時機制：畫面右上有 countdown，從 600 秒倒數。**

## 申請項目與價目（畫面 6 抄錄）

中文歷年成績表 15（立即取件）｜中文成績名次證明書 20（立即列印）｜學生證補發 200（3 工作天）｜
英文成績單 20（領取後至櫃台加蓋鋼印）｜中文在學證明書 20｜英文在學證明書 20（同鋼印）｜
中英文畢業證(明)書影本加蓋關防或鋼印 10（3 工作天）｜成績單之信封彌封 5（臨櫃）｜
中文學期成績單 15｜規整加權成績名次證明書 20（限特定獎學金）｜預期畢業(在學)證明 20（1 工作天）

## Round 1 實測路徑（照片中實際走的）

語言→學生→輸入學號生日→**中文成績名次證明書 ×1（20 元）**→在校各學期系科所名次→
114-2 學期→確認→現金→投 20 元→列印成功→結束。全程單人明眼操作順利。

## 給 demo / 語音腳本的直接素材

- 逾時 600 秒 = 語音引導的節奏上限，demo 可以做「剩餘時間提醒」
- 「勿投 1 元會當機」「先按現金再投幣」「悠遊卡記得取卡」= 三句**必進語音腳本**的在地知識，
  這正是「機台知識庫」價值的具體證據（貼紙上的知識，視障者讀不到）
- 螢幕鍵盤輸入學號生日 = demo 裡「手機端輸入、機台端免打字」的對照組痛點
- 尚缺：螢幕實體尺寸、各按鈕距離實測值（A 版腳本要用）——**這是 R1/R2 要補的**
