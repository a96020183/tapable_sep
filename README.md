## 使用流程

### 出發前（在家先做）
1. 手機開上面的網址，按任何一顆「▶ 播放」確認**有聲音**（iPhone 第一次一定要手動按）
2. 用「語速」拉桿試聽，調到聽得清楚的速度
3. 帶：**捲尺**、眼罩、零錢（十元硬幣數枚，勿帶一元）、這支手機

### 到機台現場（校園成績列印機）
4. 先量**螢幕寬、高**（公分），展開頁面最下方「實測值輸入」填進去 → A 版解鎖（數字會自動存在手機裡）
5. 看頁面「給團隊的備註」：有兩件事要先確認（學號→生日欄位怎麼切換、投幣口縫方向）

### R1（測 A 版：公分距離）
6. 切到「A 版」，受測者站到機台正前方**站定後才戴眼罩**
7. 貼紙貼在**螢幕右下角**
8. 一段一段播：播第 1 段 → 受測者照著摸 → 完成才播第 2 段，以此類推
9. 跟不上就重播，**記下是哪一句聽不懂**
10. 測完拿下眼罩，**馬上**填記錄表（趁記憶還熱）

### R2（測 B 版：手掌/指寬）
11. 切到「B 版」，流程跟 R1 完全一樣
12. R2 不比速度，只記「哪一句比較清楚、比較不用猜」

### 注意
- 選離峰時段；有人來排隊**立刻讓開、拿下眼罩**
- 現場要有網路（頁面開好就別關）
- 保險：出發前把 8 段各播一次、用另一支手機錄音備援
