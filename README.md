## 使用流程

### 出發前（在家先做）
1. 手機開上面的網址，按任何一顆「▶ 播放」確認**有聲音**（iPhone 第一次一定要手動按）
2. 用「語速」拉桿試聽，調到聽得清楚的速度
3. 帶：**捲尺**、眼罩、零錢（十元硬幣數枚，勿帶一元）、這支手機

### 到機台現場（校園成績列印機）
4. 先量**螢幕寬、高**（公分），展開頁面最下方「實測值輸入」填進去 → A 版解鎖（數字會自動存在手機裡）
5. 看頁面「給團隊的備註」：有兩件事要先確認（學號→生日欄位怎麼切換、投幣口縫方向）

### 開場鏡頭（先拍，不戴眼罩）
6. 貼紙貼在**螢幕右下角**（事先用 NFC Tools App 把 demo 網址寫進貼紙；
   測試用 iPhone 可另設捷徑自動化：NFC 掃貼紙 → 立即執行 → 打開 URL）
7. 受測者拿手機**碰貼紙 → demo 跳出來**，旁邊的人**錄影**（決賽素材）

### R1（測 A 版：公分距離）
8. 切到「A 版」→ 按黃色「**🙈 受測模式**」→ 手機交給受測者
9. 受測者站到機台正前方**站定後才戴眼罩**，先靠摸的找到貼紙（記錄：摸得到嗎、花多久）
10. 受測者自己操作手機：**點螢幕任何地方＝播下一段、兩指點一下＝重播這段**
    （進入後螢幕全黑防窺；操作員從畫面中央的大數字看進度）
11. 聽完一段 → 照著摸做完 → 再點下一段，共 4 段
12. **記下是哪一句聽不懂、卡在哪一步**
13. 測完拿下眼罩，**馬上**填記錄表（趁記憶還熱）

### R2（測 B 版：手掌/指寬）
14. 退出受測模式、切到「B 版」、再進受測模式，流程跟 R1 完全一樣
15. R2 不比速度，只記「哪一版講法比較清楚、比較不用猜」

### 注意
- 選離峰時段；有人來排隊**立刻讓開、拿下眼罩**
- 現場要有網路（頁面開好就別關）
- 保險：出發前把 8 段各播一次、用另一支手機錄音備援
