TapAble — 你的手機，接管機台

視障者用自己的手機操作沒有無障礙功能的觸控機台，機台零硬體改造。兩個 demo 是同一段旅程的兩個接力。

由 ElevenLabs 語音合成。逐字稿在下方，聽不到聲音也拿得到同樣資訊。

語音導覽逐字稿

TapAble，你的手機，接管機台。

台灣的公共服務全面觸控化。對視障者來說，每一台機器都是一面摸不到按鍵的玻璃 —— 摸不到按鍵，也不知道螢幕上有什麼。

TapAble 不改機台一根螺絲。手機鏡頭帶你走完最後十公尺；碰一下機台旁的感應貼紙，手機就知道面前是哪一台機器；接著用語音對話，一步一步陪你把事情辦完。全程螢幕全黑，旁人偷看不到。

這個頁面上有三個連結：機台操作 demo、鏡頭導引 demo，以及完整的技術文件。建議先開機台操作 demo，它在電腦上就能走完整個流程。

這段導覽由 ElevenLabs 語音合成。產品本身的語音則使用裝置端合成，確保沒有網路時也能用。

📳 機台操作 demo 主要作品不需硬體
NFC 碰一下之後的語音接管：選件 → 確認 → 付款 → 取件。此連結為「模擬付款」模式，電腦或手機直接開就能走完全流程。
📷 鏡頭導引 demo 需手機相機
最後十公尺：手機後鏡頭端側辨識，把使用者帶到機台正前方，抵達後交棒給操作段。請用手機開啟並允許相機。
🖥 模擬機台標記頁 搭配鏡頭 demo
開在另一台筆電／平板上全螢幕放著，它就是鏡頭 demo 要找的「目標機台」（會場沒有真機台的替代品）。
建議體驗順序：筆電開「模擬機台標記頁」→ 手機開「鏡頭導引 demo」走近 → 抵達後按交棒 → 自動進入「機台操作 demo」完成列印。
🗺 無障礙空間資訊 demo 長期路線
WebGIS：視障人口熱區、服務缺口、無障礙路徑 —— 決定「下一張貼紙該貼哪裡」的資料層。
